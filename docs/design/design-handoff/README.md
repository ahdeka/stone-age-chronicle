# 화면 디자인 핸드오프 (잿빛강 사람들, 1장)

이 폴더는 디자인 캔버스에서 만든 **화면 시안의 원본 코드**다. M2 이후 UI는 이 시안을 기준으로 만든다.

## 파일
| 파일 | 화면 | 역할 |
|---|---|---|
| `Main.dc.html` | 1. 인트로 | 게임 시작 시 배경 설명을 타이핑으로 보여 주고 첫 달로 들어간다 |
| `TurnModal.dc.html` | 2b. 월초 상황 화면 + 방침 팝업 | 이전안. 상황 화면과 결정 팝업을 나눈 구조는 그대로 이어받았다 |
| `Turn.dc.html` | 2. 월초 보고 (한 화면형) | 비교용 이전안. 방침 카드, 조언자 카드의 모양은 여기도 참고 |
| `Phase.dc.html` | 3. 진행 — 상순 | 이전안. 진행 중 장부와 굴러가는 숫자는 3차 피드백에서 뺐다 |
| `Situation.dc.html` | 2. 월초 상황 화면 | **2026-11-24 3차 피드백 시안, 채택.** 지표 바 → 그림 → 소식 → 사람들 → 옆줄 → 땅. 스크롤은 이 화면만 |
| `Decide.dc.html` | 2c. 결정 팝업 (두 칸) | **2026-11-24 3차 피드백 시안, 채택.** 구역 제목 한 줄 + 4열 카드, 일손 막대, 큰 일 한 줄. 스크롤 없음 |
| `Progress.dc.html` | 3. 진행 화면 | **2026-11-24 3차 피드백 시안, 채택.** 왼쪽 그림, 오른쪽 서술, 지표는 월초 기준 고정, 장부 없음. 스크롤 없음 |
| `Result.dc.html` | 4. 이달의 결과 | **2026-11-24 3차 피드백 시안, 채택.** 순별 회고, 덕분에, 사람, 장부, 연대기. 평온한 달 요약을 대신한다. 스크롤 없음 |

화면 흐름: 인트로 → 월초 상황 화면 → (결정 팝업에서 전략 선택) → 상순 → 중순(사건이 있으면 같은 팝업으로 결정) → 하순 → 이달의 결과 → 다음 달 상황 화면

**3차 피드백 원칙 (2026-11-24)**: 결정 팝업·진행 화면·이달의 결과는 1366×768(보이는 높이 약 650px)과 1920×1080에서 세로 스크롤이 없다. 진행 중에는 수치를 갱신하지 않고(지표 바는 월초 기준) 이달의 결과에서만 새 값과 증감을 보인다. 아래 §5의 "정산 행이 하나씩 들어오며 큰 숫자가 굴러간다"는 이 원칙으로 대체됐다.

## 이 파일 형식을 읽는 법
- `.dc.html`은 디자인 캔버스 전용 형식이다. **런타임(`support.js`, `<x-dc>`, `DCLogic`)은 가져오지 않는다.** 마크업, CSS, SVG, 타이밍 값만 참고해 프로젝트의 React + CSS Modules 컴포넌트로 다시 구현한다.
- `<sc-for list="{{items}}" as="item">` = 배열 렌더링(`items.map`), `<sc-if value="{{cond}}">` = 조건부 렌더링, `{{name}}` = 값 바인딩, `renderVals()` = 렌더에 넘기는 값 계산.
- `<helmet><style>`의 `@keyframes`와 클래스는 그대로 CSS Modules로 옮겨도 된다.
- 스크립트 안의 `NEWS`, `ADVISORS`, `POLICIES`, `FACTS`, `PARAS`, `ROWS`는 **예시 데이터**다. 실제로는 엔진 상태와 콘텐츠 데이터에서 온다.

## 반드시 지킬 것 (시안의 핵심)
1. **인트로**: 풍경이 서서히 나타남(약 3초) → 배경 설명 8줄을 한 글자씩 타이핑(기본 55ms/글자, 줄 사이 650ms 쉼) → 지나간 줄은 흐린 색으로 → 약 15초 뒤 부족 이름 제목과 "첫 달을 시작한다" 버튼. 건너뛰기, 남은 초, 하단 진행 막대, 다시 보기. 문장은 시작 프리셋의 브리핑 데이터에서 가져온다.
2. **상황 화면과 결정의 분리**: 월초 화면은 상황을 읽는 곳(장면 + 이번 달 소식 타이핑, 땅 정보, 사람들, 시대 목표, 부족, 아직 남은 일, 연대기). 방침은 **아래에서 올라오는 팝업(시트)**에서 고른다.
   - 팝업 상단에 핵심 수치 요약줄 고정(식량 kg·며칠분, 장작, 일손, 날씨, 이번 달 핵심 위험·기회).
   - 팝업 안에 조언자 대사.
   - 닫아도 결정은 유지. 화면 하단 고정 바에 "방침 정하기"(맥박 애니메이션) → 고른 뒤에는 "고른 방침 · 다시 보기 · 한 달을 시작한다".
   - 월초 소식 타이핑이 끝나면 한 번 자동으로 열린다(설정으로 끌 수 있게).
   - 선택하지 않으면 다음 단계로 갈 수 없다.
   - **중순 사건도 같은 팝업 컴포넌트를 쓴다.**
3. **땅 정보 카드**: 지형, 기후, 강수, 주요 강, 토양, 위험 요소 + 짧은 소개 문단. 시작 프리셋/지역 데이터에서 온다.
4. **방침 카드**: 위에 장면 그림, 번호, 위험 단서 배지(색 + 모양: ● 거의 확실하다 / ◆ 해볼 만하다 / ▲ 위험해 보인다 / ? 결과를 알 수 없다), 제목, 설명, 대가, 투입 인원. 선택 시 테두리 강조와 살짝 떠오름.
5. **진행 화면**: 상단 단계 표시(방침 ✓ → 상순 → 중순 → 하순 → 정산, 현재 단계 강조), 장면 애니메이션(동물 이동, 갈대 흔들림, 불 깜빡임), 서술 문단 타이핑(30ms/글자), 서술이 끝나면 정산 행이 하나씩 들어오며 큰 숫자가 굴러간다, 부상·사망 알림 카드, "빨리 보기"와 다음 단계 버튼.
6. **움직임 원칙**: 정적인 화면은 없다. 화면 진입은 fadeUp(0.9s, 순차 지연), 수치 변화는 굴러가는 숫자, 경고 수치는 은은한 맥박. 모든 타이핑과 애니메이션은 "빨리 보기"로 건너뛸 수 있고, 설정에서 속도를 조절한다. `prefers-reduced-motion`이면 애니메이션을 줄인다.

## 그림
- 시안의 SVG는 **동굴벽화풍 레이어 그림의 방향**을 보여 주는 예시다. 실제로는 CLAUDE.md의 그림 시스템(배경 × 주체 × 날씨 × 초상 레이어, id와 매니페스트)으로 만든다.
- 시안에 있는 장면 요소: 밤의 강 굽이와 천막·모닥불(인트로), 해 질 녘 초원과 순록 떼(월초), 여울과 달리는 순록·갈대 속 사냥꾼(상순), 방침별 썸네일 5종(순록 사냥, 강가 어로, 겨울 준비, 소규모 사냥, 늪지 탐색).
- 애니메이션 클래스(`run`, `herd`, `reed`, `fire`, `star`, `ember`, `mote`)는 레이어별 움직임으로 옮긴다.
